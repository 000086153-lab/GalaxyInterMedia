# Recursos visuales opcionales

La landing funciona sin archivos de imagen y muestra respaldos visuales en CSS.
Si después deseas usar los recursos definitivos de GalaxyInterMedia, puedes
reemplazar esos respaldos desde `public/index.php` y guardar aquí, por ejemplo:

- `logo.jpg`
- `mascota.jpg`
- `produccion.jpg`
- `marca.jpg`
- `marketing.jpg`
